# RenalSync rebrand

Website brand, document title, account copy, importer identification, and report filenames now use RenalSync. New reports use renalsync-device-report; imports accept both new and legacy schemas. Existing local storage and OAuth pending-session keys stay unchanged to preserve user data and login continuity. Historical release notes remain unchanged.

The at-home image was edited with imagegen from at-home-ui-v1.png: replace only the smartphone screen brand ClearPlate with RenalSync, preserving the photograph and screen icons. Original image retained.

Hosting domains, repository identity and external Google OAuth branding are separate configuration and are not changed by this code update.
